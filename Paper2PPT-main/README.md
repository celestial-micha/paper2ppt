**Paper2PPT** is an intelligent automation tool that transforms academic papers (PDF or LaTeX source) into professional PDF presentations. Leveraging the power of Large Language Models (LLMs), it comprehends paper content, extracts key insights, and generates structured, content-rich slides ready for presentation.

## ✨ Features

- **Multi-format Support**: Seamlessly handles both PDF documents and LaTeX project folders as input.
- **Intelligent Extraction**: Utilizes `mineru` and custom loaders to accurately extract text and structural information from papers.
- **Automated Pipeline**: A robust three-stage process: Planning, Generation, and Refinement.
- **Interactive CLI**: User-friendly command-line interface for easy paper selection and presentation duration customization.
- **Highly Customizable**: Generates standard LaTeX code that can be manually edited and compiled for perfect results.

## 📂 Directory Structure

Before using, please familiarize yourself with the key directories:

- **`paper/`**: Input directory for your academic papers.
    - `paper/pdf/`: Place PDF files here.
    - `paper/tex/`: Place LaTeX project folders here.
- **`output/`**: Destination for generated presentations.
- **`.env.example`**: Example `.env` config file.

## 🛠️ Installation

This project supports environment configuration using **Conda** or **Python venv**.

### Prerequisites

- **Python 3.12+**
- **LaTeX Distribution** (e.g., TeX Live or MiKTeX) for compiling the generated `.tex` files.
- **GPU Recommended**: For optimal performance, a GPU is suggested (Tested on V100 16G).

### Method 1: Using Conda (Recommended)

1.  **Create and activate environment**
    ```bash
    conda create -n paper2ppt python=3.12
    conda activate paper2ppt
    ```

2.  **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

### Method 2: Using venv

1.  **Create virtual environment**
    ```bash
    python -m venv venv
    ```

2.  **Activate environment**
    - Linux/macOS:
        ```bash
        source venv/bin/activate
        ```
    - Windows:
        ```bash
        .\venv\Scripts\activate
        ```

3.  **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

## ⚙️ Configuration

Create a `.env` file in the project root directory to configure LLM-related environment variables. You can copy the provided `.env.example` file:

```bash
cp .env.example .env
```

**Example `.env` file content:**

```env
# Standardized Configuration
API_PROVIDER=deepseek
MODEL_NAME=deepseek-chat
LLM_API_KEY=your_api_key_here
LLM_API_BASE=https://api.deepseek.com
```

## 🚀 Usage

1.  **Prepare Data**
    - Place PDF papers in `paper/pdf/`.
    - Unzip LaTeX source code into a subdirectory under `paper/tex/` (e.g., `paper/tex/attention_is_all_you_need/`).

2.  **Run Program**
    Ensure your Python environment is activated, then run:

    ```bash
    python main.py
    ```

3.  **Interactive Operation**
    - The program scans `paper/` for available papers.
    - Select a paper by entering its corresponding number.
    - Input the desired presentation duration (in minutes), e.g., `25`.

4.  **Get Results**
    - Results are generated in the `output/` directory (e.g., `output/<paper_name>_pdf/`).
    - Compile the `presentation.tex` to get your slides:
        ```bash
        cd output/your_paper_folder
        pdflatex presentation.tex
        # OR
        latexmk -pdf presentation.tex
        ```
